# 使用指南

**[English](USAGE.md) | 简体中文** · [返回首页](../README_ZH.md)

## 设置范围

框选矩形、使用当前视图、输入边界或导入矢量。导入读取外接矩形，不按面边界精确裁切。请目视检查范围并提供正确的源坐标系。

## 各模块操作

- **底图瓦片：**选择图源及层级，检查预计瓦片数，设置输出 GeoTIFF 和坐标系后下载。
- **历史影像：**刷新版本清单，选择日期后下载；版本日期不一定是拍摄日期。
- **卫星影像：**设置日期和云量，检索后检查覆盖，勾选场景及波段再下载。
- **矢量数据：**选择服务与要素类别，导出后核对属性和几何。
- **土地覆盖：**选择产品与年份，结合对应分类图例解读专题栅格。
- **农田地块：**选择年份及 GeoJSON/GeoPackage；查看日志中的格式处理结果。
- **AW3D30：**填写自己的 JAXA 账号，计算所需图幅，设置输出与解压选项后下载。
- **GIF：**选择本地 GeoTIFF 文件夹及动画参数，启用日期标签前核对文件命名与顺序。

## 常见问题

| 现象 | 处理方向 |
|---|---|
| 提示注册 | 私下联系开发者获取与本机匹配的有效授权码 |
| 缺少组件 | 重新完整解压程序包 |
| 地图空白或请求失败 | 检查网络、服务状态、权限、限流和证书 |
| 结果偏移 | 核对源坐标系、底图偏移及已知控制位置 |
| 内存不足 | 缩小范围、降低层级或分区处理 |
| 局部灰块 | 检查失败瓦片日志，缩小请求重试 |
| 无卫星场景 | 检查覆盖、日期、云量和数据集 |
| 范围大于预期 | 导入面取外接矩形，拼接可能扩展到瓦片边界 |

停止属于协作式取消，当前网络请求或处理步骤可能结束后才响应。中途生成的文件不能视为完整成果。

[反馈问题](https://github.com/zhangyhrs/map_tile_downloader/issues)时说明程序版本、Windows 版本、模块、复现步骤和脱敏日志，不公开凭据、机器码、涉密坐标或私人路径。
